# Signal Digital Lab

A responsive, static website for Signal Digital Lab. It includes the original brand logo, services, approach, video portfolio, design gallery, FAQs, and contact links.

## Run locally

Open `index.html` in a browser, or serve the directory with a static server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Publish the repository root as a static site. No build command or environment variables are required. On Netlify, leave the build command blank and set the publish directory to `.`.

## Media

Optimized videos and poster frames live in `media/`. The design gallery images are concept visuals, not client results. The original Signal Digital Lab logo is stored as `signal-digital-lab-logo.png` and is layered onto the gallery in HTML to keep it exact.
